The HTTP API has two public surfaces:

| Surface | Use it for | Resource audience |
| --- | --- | --- |
| Agent | Stateful turns, progress, actions, and sessions | `/v1/agent` |
| Pipeline | Stateless catalog discovery and Build execution | `/v1/pipeline` |

These roots identify OAuth resource audiences; they are not directory endpoints. Start Agent calls at `/v1/agent/chat` or `/v1/agent/sessions`, and Pipeline discovery at `/v1/pipeline/apps`, `/skills`, `/evm`, or `/svm`.

Use `@aomi-labs/client` for TypeScript. It manages guest sessions, OAuth resources, schemas, errors, and idempotency for you.

## Base URL

Keep the origin in environment configuration:

```bash
export AOMI_BASE_URL="https://chat-staging.aomi.dev"
```

Production and staging can expose different API versions during a rollout. Use the URL provisioned for your integration.

## Authentication

Direct OAuth calls use a bearer bound to the exact resource:

```bash
curl "$AOMI_BASE_URL/v1/pipeline/apps" \
  -H "Authorization: Bearer $AOMI_ACCESS_TOKEN"
```

An OAuth Agent token cannot be reused for Pipeline. An environment-issued guest bearer can cover the guest-safe scopes enabled by that environment. See [Authentication](/integrate/authentication) for guest, OAuth, and widget flows.

| Resource | Common scopes |
| --- | --- |
| `/v1/agent` | `agent:read`, `agent:write`, `agent:actions:resolve` |
| `/v1/pipeline` | `pipeline:catalog`, `pipeline:execute` |
| `/v1/agent/mcp` | MCP Agent access plus required Agent scopes |
| `/v1/pipeline/mcp` | MCP Pipeline access plus required Pipeline scopes |

## Request conventions

- Send and receive JSON unless an endpoint returns a document.
- Send `Idempotency-Key` with mutations that can create effects.
- Reuse one idempotency key only for retries of the same logical request.
- Keep Agent cursors opaque.
- Capture `X-Request-Id` from every failed response.
- Respect `Retry-After` on throttled or deferred requests.

## Schema availability

`chat-staging.aomi.dev` does not currently publish a document at `/openapi.json`. Use the released TypeScript client for generated request and response types, or use the endpoint contracts in this section. Do not make production startup depend on that URL.
