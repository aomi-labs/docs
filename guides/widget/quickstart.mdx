Install the widget in a React 18 or 19 application:

```bash
npm install @aomi-labs/widget
```

Add this client component. Replace `123` with your activated App's Application ID.

```tsx
"use client";
import { AomiWidget } from "@aomi-labs/widget";
import "@aomi-labs/widget/styles.css";
export default function Assistant() { return <AomiWidget applicationId="123" />; }
```

The widget uses `https://chat.aomi.dev` by default. Guest chat starts without
loading Para or Privy. Users can connect a browser wallet when they need to sign.
Register the exact host origin for your App before testing authentication;
production embeds require HTTPS.

`applicationId` identifies the hosted App and scopes its state. It does not
select a Direct routing target. Set `routing` separately when your integration
needs Direct execution.

For another deployment, pass an explicit absolute `apiUrl`. A local HTTP origin
requires a service configured for local development. The package does not read
Next.js environment variables or require a custom Vite configuration.

Continue with [optional wallets](/guides/widget/installation) or
[layout and routing](/guides/widget/customization).
