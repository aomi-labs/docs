---
title: "Ship on Vercel"
description: "Deploy an App-bound Aomi widget to Vercel and verify that the public frontend reaches the configured App."
---

## Before you start

You need an activated Aomi App, a working local widget, Node.js 20 or newer, and a Vercel account.

## Build locally

```bash
npm run build
```

Confirm that the production build can sign in and send a message from your registered local origin.

## Deploy

```bash
npm install --global vercel
vercel
vercel --prod
```

Point the widget at the backend in **Settings → Environment Variables**:

```bash
NEXT_PUBLIC_BACKEND_URL=https://api.aomi.dev
```

`AomiFrame` resolves the backend from the `backendUrl` prop first, then `NEXT_PUBLIC_BACKEND_URL`, then `http://localhost:8080`. To pin the page to one App, pass `applicationId` to `AomiRuntimeProvider` (a prop, not an environment variable). Register the production Vercel URL as an allowed origin before testing authentication.

<Warning>
  Never add App keys, provider secrets, paymaster credentials, or gas-policy credentials to frontend environment variables.
</Warning>
