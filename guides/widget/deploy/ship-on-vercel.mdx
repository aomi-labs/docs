---
title: "Ship on Vercel"
description: "Deploy your widget host and verify it from its registered production origin."
---

Start with a working [widget quickstart](/guides/widget/quickstart), an activated
App and a Vercel account. Build your frontend locally:

```bash
npm run build
```

Deploy through your existing Vercel project or the Vercel CLI, then register the
exact production origin for your App. Allow that origin in your wallet provider
when required. Open the deployed page, send a guest message, connect a wallet
and review an action.

The widget defaults to `https://chat.aomi.dev`. Pass `apiUrl` explicitly for
another deployment. Provider identifiers are public host configuration passed
through the auth factory; the package does not read environment variables.

Do not expose App secrets, provider secrets or private keys in frontend code.
