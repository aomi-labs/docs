---
title: "Troubleshooting"
description: "Resolve common widget authentication, wallet, and sponsored-execution problems."
---

| You see | Check |
| --- | --- |
| Widget does not render | Package styles, `apiUrl`, and Application ID |
| Origin rejected | The exact scheme, host, and port registered for the App |
| Sign-in does not complete | Provider environment and the active browser session |
| Wallet cannot sign | The active wallet supports personal-message signing |
| Owner or network mismatch | Switch back to the owner and network shown in the request |
| AA account unavailable | The App supports the selected network and the owner is bound |
| Fee balance insufficient | The executor holds the asset required for the disclosed fee |
| Sponsorship unavailable | Retry later or contact the App operator; there is no unsponsored fallback |
| Operation expired | Start the action again and sign the new request |

Do not include session tokens, provider credentials, full signatures, or secret configuration in support messages.
