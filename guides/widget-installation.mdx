---
title: "Widget installation"
description: "Install the compiled Aomi widget from npm."
---

Install the compiled package:

```bash
npm install @aomi-labs/widget
```

```tsx
"use client";
import { AomiWidget } from "@aomi-labs/widget";
import "@aomi-labs/widget/styles.css";
export default function Assistant() { return <AomiWidget applicationId="123" />; }
```

Follow the [widget quickstart](/guides/widget/quickstart) for origin registration,
[installation guide](/guides/widget/installation) for optional wallet providers,
and [customization guide](/guides/widget/customization) for layout and routing.

Existing registry installs continue using frozen JSON during the announced
retention window. New integrations use npm and do not require Tailwind, shadcn
initialization or copied component source.
