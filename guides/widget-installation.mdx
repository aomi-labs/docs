---
title: Widget installation
description: Choose the packaged Aomi widget or own its component source.
---

Use the packaged widget for a new embed:

```bash
npm install @aomi-labs/widget-lib
```

Follow [Installation](/guides/widget/installation) to configure the API origin, Application ID, and browser-wallet, Para, or Privy authentication. Follow [Quickstart](/guides/widget/quickstart) for a complete frontend scaffold.

For a custom UI, use the [headless library](/integrate/ui/headless-library). Authentication identifies the caller; it does not grant unattended wallet signing.
