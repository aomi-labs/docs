Use the [widget quickstart](/guides/widget/quickstart) to install the compiled
`@aomi-labs/widget` package. It includes the styles and browser-wallet integration;
Tailwind, shadcn initialization and copied component source are not required.

For optional Para or Privy wallets, follow the [installation guide](/guides/widget/installation).
For your own interface, use the [React headless library](/integrate/ui/headless-library).
