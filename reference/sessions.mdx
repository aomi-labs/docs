---
title: Sessions
description: Create, resume, and manage conversations through the versioned Agent API.
---

An Agent session is a persisted conversation. Its ID is not an account credential or permission to sign a transaction.

## Create and continue a conversation

```ts
import { Aomi } from "@aomi-labs/client";

const aomi = new Aomi({ baseUrl: process.env.AOMI_BASE_URL! });
const sessionId = crypto.randomUUID();

await aomi.agent.run("Remember that I prefer Base.", { sessionId });
const result = await aomi.agent.run("Which chain do I prefer?", { sessionId });
console.log(result.messages);
```

For raw HTTP, send `sessionId` and `message` in the JSON body of `POST /v1/agent/chat`, with a caller credential and `Idempotency-Key`. Do not put messages or secrets in URL query parameters. See the [Agent reference](/api-reference/agent).

## Restore history and progress

Read `GET /v1/agent/chat/{sessionId}` to hydrate the ordered event ledger. Continue with the returned opaque cursor; never construct or decode one yourself. The stream at `/v1/agent/chat/{sessionId}/stream` delivers progress. Keep provisional text separate from durable events and recover an invalid cursor by hydrating without it.

Current source can also return durable Commit views in `EventPage.commits`. Render their latest review and status separately from typed Actions. See [wallet and signing](/integrate/actions-and-signing).

## Manage session metadata

```ts
const sessions = aomi.raw.agent.sessions;
const page = await sessions.list({ limit: 20 });
console.log(page);
await sessions.update(sessionId, { title: "Base research" });
await sessions.update(sessionId, { archived: true });
```

Session list records contain metadata, not a second transcript. Use pagination for long lists. Account-owned history and mutations require the scopes accepted by your environment. Guest identity is limited by the client lifetime and host policy.

To stop active work, use `run.interrupt()`. Archiving hides a conversation from normal lists; it does not grant or revoke wallet authority.

See [Client SDK compatibility](/integrate/client-sdk#check-compatibility) before using current-source features with a published package or hosted environment.
