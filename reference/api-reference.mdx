The current public HTTP API is versioned under `/v1`. The earlier `/api/chat`,
`/api/state`, `/api/updates`, and `AOMI-APP-KEY` examples that once lived on
this page are retired integration contracts.

Use the canonical reference pages:

- [API overview](/api-reference/overview) for the public origin, authentication,
  idempotency, and request conventions.
- [Agent REST API](/api-reference/agent) for turns, event pages, SSE, sessions,
  interrupts, and action results.
- [Pipeline REST API](/api-reference/pipeline) for discovery and the
  build → simulate → commit lifecycle.
- [Authentication reference](/api-reference/authentication) for exact OAuth
  resources and scopes.

The `/openapi.json` document on a public API origin describes the contract
deployed in that environment. The published [API overview](/api-reference/overview)
identifies the source revision used for this reference. In TypeScript, prefer
the [Client SDK](/integrate/client-sdk), which wraps the same versioned
resources and validates their schemas.
