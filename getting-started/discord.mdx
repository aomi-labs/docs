Discord support is on the way. You’ll be able to make your deployed Aomi App available in Discord so people can use it from a server or direct message.

<Note>
  Discord is not available yet. Use [Telegram](/build/telegram) or the [portal](https://chat.aomi.dev) while we finish it.
</Note>

## What to expect

- Server and direct-message support
- Streaming responses and visible tool results
- Slash commands and persistent conversation context
- A non-custodial wallet handoff for transaction approval

We’ll replace this page with the complete setup guide when the Discord channel is ready.
