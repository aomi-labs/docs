## What it does

- Reads idle portfolio assets.
- Retrieves current venue and asset risk context.
- Assesses a candidate position before recommending it.
- Presents the recommendation as structured UI instead of raw model text.
- Keeps approval with the user before a strategy change proceeds.

## How it uses Aomi

The Somm App wraps the product's existing APIs as typed tools. A system prompt gives the agent its investment mandate. The frontend renders the resulting recommendation as a product-native card.

Aomi hosts the agentic loop and makes the App available through the deployed Somm experience. Somm keeps ownership of its strategy logic, data, risk model, and interface.

## Why it is a useful example

Somm shows how to add an agentic interface to established financial software without rebuilding the product inside the model. Existing APIs remain the source of truth. The App gives the model a small, explicit tool surface and turns its output into a reviewable action.
